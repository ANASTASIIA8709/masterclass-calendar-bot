# ИИ-секретарь с Google Календарём

Пишешь в бота как в обычный чат — он добавляет событие в Google Calendar. Claude понимает свободный текст: с датами, временем, именами. Это готовая основа к Дню 5 курса «ИИ-боты для турагентов».

## Что умеет бот

- Добавить событие по тексту: «встреча с Ивановым в пятницу в 14:00» → событие в Google Календаре
- Несколько событий сразу: «завтра звонок в 10 и встреча в 15» → два события
- Показать расписание: «что у меня сегодня?» / «что завтра?» / «что на этой неделе?»
- Команды `/today`, `/tomorrow`, `/week` — быстрый просмотр

## Что нужно заранее

1. Аккаунт в Telegram.
2. Токен бота: @BotFather → `/newbot`. Токен нельзя писать в код и в чат.
3. Свой Telegram ID через @userinfobot.
4. Аккаунты GitHub и Railway, как в Дне 0 курса.
5. Ключ Claude API: зарегистрируйся на [console.anthropic.com](https://console.anthropic.com), создай API-ключ. На новом аккаунте есть бесплатные $5.
6. Google Calendar и сервисный аккаунт — как в Дне 5 курса. Коротко:
   - в Google Cloud создай проект, включи Google Calendar API, скачай JSON-ключ сервисного аккаунта;
   - в настройках Google Calendar добавь email из поля `client_email` JSON-ключа с правом «Изменять события»;
   - скопируй ID календаря (Настройки → Интеграция) или используй слово `primary`.

## Как запустить на Railway

1. Нажми **Fork** — получишь свою копию.
2. Войди на [railway.app](https://railway.app) через GitHub.
3. Нажми **New → GitHub Repository**, выбери свою копию.
4. Открой **Variables** и добавь все переменные из таблицы ниже.
5. Напиши боту `/start` и попробуй: «встреча завтра в 11».

## Переменные (Railway → Variables)

| Переменная | Обязательна? | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен из @BotFather |
| `OWNER_ID` | да | твой Telegram ID |
| `ANTHROPIC_API_KEY` | да | ключ с console.anthropic.com |
| `CALENDAR_ID` | да | ID календаря или слово `primary` |
| `GOOGLE_CREDENTIALS_JSON` | да | весь JSON сервисного аккаунта одной строкой |

## Как адаптировать

**Часовой пояс:** бот работает в Москве (UTC+3). Для другого пояса найди в `bot.py` строку `timedelta(hours=3)` и замени.

**Другой язык для событий:** формат ответа Claude задан в функции `parse_with_claude`. Добавь туда инструкции на нужном языке.

**Несколько человек:** убери проверку `only_owner` или добавь список разрешённых ID.

**Напоминания:** в функцию `create_event` добавь поле `reminders` по документации Google Calendar API.

## Как понять, что всё получилось

- «встреча завтра в 10» → бот отвечает «✅ Добавлено» и событие видно в Google Calendar.
- «что сегодня?» → бот показывает список событий.
- Событие без времени («день рождения 15 декабря») добавляется как весь день.

## Если не работает

- **Claude не отвечает / ошибка 401.** Неверный `ANTHROPIC_API_KEY`. Проверь в Variables — без пробелов.
- **Ошибка Calendar / 403.** Календарь не открыт для email сервисного аккаунта, или `GOOGLE_CREDENTIALS_JSON` вставлен не полностью.
- **Бот не понимает дату.** Уточни формат: «в пятницу», «14 ноября», «завтра».
- **Бот в Telegram молчит.** Проверь `BOT_TOKEN` в Variables. Посмотри логи в Railway.
